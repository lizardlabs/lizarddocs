# LizardDocs

**Markdown in. A complete static documentation site out. Built with .NET.**

Turn project documentation into a static website with navigation, on-page contents, ranked search and readable code examples. Choose a different name, logo, colour and footer for each project.

Created by [Lizard Labs Software](https://lizard-labs.com/).
See LizardDocs in use: [DirectSharp documentation](https://direct-sharp.lizard-labs.com/), a site generated from Markdown.

## Read and find

Search prioritizes page titles, then section headings, then body text. Results highlight matching words and link directly to the matching section. Search also works when the generated files are opened from disk.

## Publish ordinary files

Build named pages such as guide/getting-started.html. Upload the generated ZIP and extract its contents into your web directory. The host needs no .NET application, database, Python or Node.

[Start with a small site](guide/getting-started.md), [configure the branding](configuration.md), or [read the command reference](commands.md).
